# Quiz App

A cross‑platform quiz application built with **Flutter** for Windows, macOS, and Android, plus a lightweight **Node.js** backend for online sync.

## Project Structure

```
quiz_app/
├─ lib/
│  ├─ main.dart
│  ├─ screens/
│  ├─ widgets/
│  ├─ models/
│  └─ services/
├─ assets/
│  └─ fonts/
├─ backend/
│  ├─ server.js
│  └─ db/schema.sql
└─ pubspec.yaml
```

Run the Flutter app with `flutter run` (select Windows/macOS/Android target). The backend can be started with `node backend/server.js`.
